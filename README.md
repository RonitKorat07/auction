# Auction Five Sigma

A full-featured auction platform where Users can register, login, and watch live auctions. Only the team can place bids. Admins manage auctions and monitor activity.

## Features

- User registration and login  
- Live auction bidding with real-time updates  
- View bid history and auction results  
- Admin panel to create and manage auctions  
- Multiple pages including Login, Dashboard, Auction List, and History  

## How It Works

Users sign up and log in to access live auctions. team can place bids and track their history. Admins control auction creation and user management.
